# سلف تلگرام — نسخه اصلاح‌شده

این پروژه بر پایه Kurigram/Pyrogram است، نه Telethon. قابلیت‌های Word و PDF حذف شده‌اند.

## راه‌اندازی
- Python 3.14 و FFmpeg لازم است. Dockerfile محیط پیشنهادی را مشخص می‌کند؛ ساخت Docker و استقرار Railway در این محیط آزمایش نشده‌اند.
- `python -m venv .venv` و سپس `pip install -r requirements.txt` در محیط مجازی.
- متغیرهای محیطی را در پنل سرویس یا shell تنظیم کنید؛ فایل `.env` خودکار خوانده نمی‌شود.
- اجرا: `python bot.py`
- در Railway یک Volume پایدار روی `/data` متصل و `DATA_DIR=/data` تنظیم کنید. تنها یک replica اجرا کنید.

## تنظیمات ضروری
- `API_ID` و `API_HASH`: اطلاعات برنامه تلگرام.
- `BOT_TOKEN`: توکن ربات مدیریت.
- `GOD_ADMIN_IDS`: شناسه عددی مدیران، جداشده با کاما.
- `ALLOWED_USER_IDS`: شناسه حساب‌های مجاز برای ورود؛ پیش‌فرض مدیران هستند. بدون فهرست مجاز، ورود بسته است.
- `SESSION_ENCRYPTION_KEY`: کلید ثابت Fernet برای رمزنگاری نشست‌ها. دستور ساخت در SECURITY.md آمده است. کلید را در Secretهای سرویس نگه دارید و با هر اجرا عوض نکنید.
- `DATA_DIR`: مسیر خصوصی داده پایدار.
- اختیاری: `AI_API_KEY`، `AI_API_URL` (HTTPS endpoint سازگار chat completions)، `AI_MODEL`.

## استفاده
ربات مدیریت را start کنید و از دکمه ارسال مخاطب متعلق به خودتان استفاده کنید. ورود دارای محدودیت تلاش و انقضاست. رمز و کد ورود را در چت‌های دیگر یا برای افراد نفرستید.

- `پنل`، `راهنما`
- `.ربات سؤال`؛ فعال‌سازی با `دستیار روشن`
- `.ویس متن` یا ریپلای `.ویس`
- `.id`، `.پینگ`
- `ساعت روشن/خاموش`
- `ذخیره پیوی روشن/خاموش`

آهنگ هنوز قابلیت آماده‌ای نیست. APIهای بیرونی ابزارها و سرویس ویس ممکن است تغییر کنند.

## ارتقا و حریم خصوصی
پیش از جایگزینی، از Volume و کلید رمزنگاری بکاپ امن بگیرید. نشست‌های قدیمی هنگام خواندن مهاجرت می‌کنند؛ نسخه‌های قدیمی دیتابیس/بکاپ ممکن است همچنان حاوی نشست خوانا باشند. حذف داده محلی، Saved Messages یا بکاپ‌های قبلی را حذف نمی‌کند. SECURITY.md را بخوانید.

## تست
`pip install -r requirements-dev.txt`
`python -m pytest -q`

تست‌ها آفلاین‌اند و مرز تلگرام/AI/TTS را شبیه‌سازی می‌کنند. تأیید اتصال واقعی، محدودیت حساب، قالب پیام و استقرار سرور نیاز به آزمایش با حساب آزمایشی دارد. هیچ تضمین بدون‌باگ یا جلوگیری از محدودیت تلگرام وجود ندارد. ارسال مجدد آرشیو پس از قطع شبکه ممکن است بعضی قطعه‌های تحویل‌شده را تکرار کند (at-least-once).
