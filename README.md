# سلف‌تلتون (نسخه ماژولار و بهینه‌شده برای Railway)

## متغیرهای محیطی (Variables) روی Railway
- `API_ID`: از my.telegram.org
- `API_HASH`: از my.telegram.org
- `BOT_TOKEN`: توکن ربات مدیریتی از BotFather
- `GOD_ADMIN_IDS`: آی‌دی عددی مدیر(ها)، با کاما جدا شود
- `AI_API_KEY`: کلید سرویس AI
- `AI_API_URL`: آدرس endpoint سرویس AI
- `AI_MODEL`: نام مدل
- `DATA_DIR`: مسیر Volume پایدار روی Railway (مثلاً `/data`)

## دستورات کلیدی
- `پنل` — باز کردن پنل شیشه‌ای رنگی
- `.ربات <سؤال>` — پرسش از دستیار هوش مصنوعی (فقط پیام خودتان)
- `.id` / `.ایدی` — نمایش اطلاعات خودتان یا فرد ریپلای‌شده + تخمین زمان ساخت
- `.ping` / `.پینگ` — پینگ تا تلگرام و وضعیت CPU/RAM/دیسک سرور
- `.ویس <متن>` یا ریپلای `.ویس` — تبدیل متن به ویس فارسی (انتخاب صدای زن/مرد در پنل)
- `.اهنگ <نام>` / `.آهنگ <نام>` — به زودی تکمیل می‌شود
- `ذخیره پیوی روشن/خاموش` — آرشیو پیام‌های حذف‌شده و مدیای تایم‌دار در پیوی اشخاص
